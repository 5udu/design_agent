# 工作区UI检查

日期：2026-11-03。检查对象为当前项目列表与图像对话工作区，结合桌面、390px手机及短屏视口验证。

## 本轮已实施

| 原有问题 | 当前行为 |
| --- | --- |
| 项目列表只有进入操作，无法整理历史项目 | 增加删除入口、确认、取消、失败重试和完成通知；手机端直接显示删除按钮 |
| 删除当前或最后一个项目后容易残留选择、图片和订阅 | 切换到剩余项目或空工作区，清除旧参考、URL与选择；其他页面同步退出已删除项目 |
| 搜索无结果时列表空白 | 显示无结果说明与清空入口，新建项目时清空搜索 |
| 固定高度输入框占用空间，长输入滚动不方便 | 默认更紧凑，按内容增高到160px；手机使用16px输入字号，短屏保留输入区域 |
| 当前参考图只有通用文案 | 显示图片名称，支持移除并开始新创作 |
| 长对话向上查看后返回末尾不方便 | 增加回到底部按钮，不强行打断向上阅读 |
| 新建/删除弹窗键盘操作不完整，错误提示可能被遮挡 | 焦点进入弹窗、Tab循环、Escape退出并返回入口；错误显示在对应弹窗内 |
| 辅助文案过浅、小屏操作目标偏小 | 提高过程文字对比度，扩大手机删除按钮，并支持减少动画偏好 |

验证脚本为scripts/verify_session_workspace.py，使用隔离数据库及本地模型/图片替身，覆盖会话、生成、编辑、询问恢复和删除全过程。页面证据在outputs/session-context。
